# Recovered Acorn Z80 media

These 409,600-byte DSD images were supplied by the repository owner, who explicitly approved publishing the complete media set in this repository. They are emulator inputs and are not covered by the source code's MIT licence. Inclusion here does not assert ownership of third-party software recorded in the images.

Exact hashes, identification status and validation evidence are recorded in [`docs/acorn-z80-media.md`](../docs/acorn-z80-media.md). `CPM_Utilities_Disc.dsd` is the pinned system image used by `npm run test:bbc-cpm`; other images are not presented as validated applications until their individual launch gates pass.
