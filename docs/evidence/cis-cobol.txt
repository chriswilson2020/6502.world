The supplied PI.CBL example compiles without errors and creates PI.INT. The
test requires real 8271 writes, a dirty private drive-1 clone, an unchanged
bundled CIS COBOL source hash, and the same PI.INT directory entry after
exporting and remounting the modified application DSD read-only.

The browser launch action starts the interactive compiler as COBOL; compiling
files requires the writable session copy mounted by the preset.
